#Proyecto para la plataforma Coder House

Este proyecto se basa en la consigna final de un trabajo de Coder House. Crear 5 archivos html responsivos, con la incorporación de CSS, Flex, Grids, Bootstrap, SASS y animaciones. Así mismo la personalización de Bootstrap también ha sido aplicada.


El sitio web está inspirado en el videojuego Stardew Valley de Barone.


Solo se necesita un navegador para poder ejecutar el proyecto.
